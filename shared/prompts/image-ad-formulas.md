# Image Ad Prompt Formulas

Reusable prompt templates for static image ads across all providers.

## Gallery Styles (Photoreal)

### Product Hero

```
Create a product hero image: [PRODUCT], centered on a clean, minimalist background.
High-end studio lighting, sharp focus, premium aesthetic, clear product geometry, no text overlays.
Aspect ratio: [RATIO]. Quality: ultra-premium, magazine-ready.
```

### Lifestyle / UGC

```
Create a UGC-style product image: person holding [PRODUCT] in a [SETTING], natural daylight,
handheld smartphone aesthetic, visible skin texture, minor imperfections, authentic emotion.
No text overlays. Aspect ratio: [RATIO].
```

### Flat-lay Showcase

```
Create a flat-lay product showcase: [PRODUCT] arranged artfully with complementary items
on a clean surface. Soft, directional lighting, sharp focus on product, creative composition.
Aspect ratio: [RATIO]. Premium, polished, editorial quality.
```

## UI / Typography Styles (GPT Image)

### Apple Notes Style

```
Create an Apple Notes app screenshot ad: yellow note-taking interface with handwritten-style
text describing the product benefit. Clean, minimalist, mobile-optimized.
Aspect ratio: [RATIO].
```

### Comparison Table

```
Create a side-by-side comparison table: "Before [COMPETITOR]" vs. "After [PRODUCT]".
Clean table layout, checkmarks and crosses, professional typography, high contrast.
Aspect ratio: [RATIO].
```

### Slack Message Thread

```
Create a fake Slack message thread: team members discussing how [PRODUCT] solved their problem.
Realistic Slack UI, profile pictures, timestamps, emoji reactions. High engagement indicators.
Aspect ratio: [RATIO].
```

## Video Thumbnail Styles

### Reaction Shock

```
Create a YouTube thumbnail: shocked human reaction, mouth open, eyes wide, holding [PRODUCT].
High contrast colors, bold sans-serif text (max 3 words), arrow or circle callout.
Aspect ratio: 16:9 (1280x720).
```

### Before/After Split

```
Create a YouTube thumbnail split-screen: LEFT side shows "Before" (tired, unhappy),
RIGHT side shows "After" (energized, happy with product). Huge arrow between. Bold text.
Aspect ratio: 16:9 (1280x720).
```

---

**Guardrails:**
- Never use real trademarked logos without explicit permission
- Keep text minimal and legible at small thumbnail size
- Prioritize subject clarity and contrast over background details
- Use consistent brand colors if provided
