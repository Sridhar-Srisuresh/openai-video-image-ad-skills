# Generated Outputs

All generated ads (videos, images, thumbnails) are saved here.

## Organization

Subfolder per workflow:

```
outputs/
├── seedance-ugc/          # UGC videos
├── product-hero/          # Product hero videos
├── static-ads/            # Image ads and thumbnails
├── pixar-ads/             # Pixar-style multi-beat clips
├── claymation-ads/        # Claymation sequences
└── clone-variations/      # Variations of cloned ads
```

## File Naming

Descriptive, not job IDs:

```
outputs/seedance-ugc/woman-in-kitchen-blue-product-v1.mp4
outputs/static-ads/hero-lifestyle-square-variation-2.jpg
outputs/pixar-ads/4-beat-reveal-final.mp4
```

## Notes

- Always open the folder so you can review the output immediately
- Files remain local and are never automatically deleted
- Quality-check every video before use (see skill documentation for QA checklist)
